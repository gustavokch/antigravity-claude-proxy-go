3. Claude 5.5 Model Specifications
----------------------------------
Claude 5.5 family replaces the earlier Claude 4.6 family (`claude-sonnet-4-6`, `claude-opus-4-6`).

Key specifications:
- Context limit (`maxTokens`): 1,000,000 tokens
- Max output limit (`maxOutputTokens`): 128,000 tokens
- Thinking levels: Upstream Cloud Code PA uses integer `thinkingLevel`
  (matches Vertex content.proto / PredictionService ThinkingLevel enum):
    * 1 = Low (`THINKING_LEVEL_LOW`)
    * 2 = Medium (`THINKING_LEVEL_MEDIUM`)
    * 3 = High (`THINKING_LEVEL_HIGH`)
    * 4 = Minimal (`THINKING_LEVEL_MINIMAL`, preserved in parser)
- Models published upstream:
    * `claude-opus-5-5-low`    (thinkingLevel: 1)
    * `claude-opus-5-5-medium` (thinkingLevel: 2)
    * `claude-opus-5-5-high`   (thinkingLevel: 3)
    * `claude-sonnet-5-5-low`    (thinkingLevel: 1)
    * `claude-sonnet-5-5-medium` (thinkingLevel: 2)
    * `claude-sonnet-5-5-high`   (thinkingLevel: 3)
- Upstream flags:
    * `supportsThinking`: true
    * `supportsAdaptiveThinking`: true
    * `supportsImages`: true
    * `apiProvider`: "API_PROVIDER_ANTHROPIC_VERTEX"
    * `modelProvider`: "MODEL_PROVIDER_ANTHROPIC"
    * `vertexModelId`: "claude-opus-5-5@default" and "claude-sonnet-5-5@default"

4. Claude 4.6 Deprecation Status
--------------------------------
- Claude 4.6 models (`claude-sonnet-4-6`, `claude-opus-4-6`, `claude-opus-4-6-thinking`)
  have been removed from `agentModelSorts` and `models` on migrated accounts.
- Upstream returns the following error when querying Claude 4.6 on migrated accounts:
  "Claude Sonnet 4.6 is no longer available. Please switch to Claude Sonnet 5.5."
- Proxy backwards-compatibility requirement:
  Legacy requests referencing `claude-sonnet-4-6`, `claude-opus-4-6`, etc. must be
  gracefully routed/aliased to their corresponding Claude 5.5 equivalents, while
  respecting account-level catalog definitions if an unmigrated account still provides them.
